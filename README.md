## Overview

**VEGA BANK GAME** is a Telegram banking and economy game module that lets users create virtual bank accounts, earn in-game currency, transfer money, invest in virtual assets, and compete on leaderboards.

The module adds a collection of interactive economy features to a Telegram bot, including jobs, salaries, scratch codes, treasure hunts, a wheel of fortune, stock-style investments, and player-versus-player activities.

> **Important:** This is a fictional game economy. Account numbers, balances, and card-like details generated by the bot are simulated game data. They are not real bank accounts, payment cards, or financial services.

## Features

### Virtual Bank Accounts
- Create a virtual account by choosing from three in-game banks.
- Receive a generated account number.
- Start with a bank-specific virtual balance.
- Generate simulated card-style details for the game.
- View account information and creation date.
- Delete your own virtual account.
- Check your current balance.
- View another player's balance by replying to their message.

### Money Transfers
- Transfer virtual currency to another player's account.
- Identify recipients using their in-game account number.
- Validate the recipient and transfer amount.
- Prevent transfers to your own account.
- Check available balance before completing a transfer.
- Record transfer details in the transaction data.

### Jobs & Rewards
- Claim a salary from a randomly assigned in-game job.
- Choose from multiple job types, each with its own salary range.
- Receive random tips.
- Earn rewards through timed activities.
- Use cooldowns to control how frequently rewards can be claimed.

### Investments & Virtual Stocks
- Invest a selected amount of virtual currency.
- Experience randomized profit or loss results.
- Buy from several fictional stock categories.
- View your current investment portfolio.
- Sell a selected virtual stock.
- Sell all held stocks through a single command.
- Track investment values and recorded results.

### Games & Chance Activities
- Play a chance-based game using your virtual balance.
- Try the wheel of fortune for randomized prizes.
- Search for a virtual treasure.
- Use scratch codes to claim randomized rewards.
- Receive unique, time-limited codes.
- Prevent reuse of already redeemed or expired codes.

### Player Interaction
- Attempt a fictional in-game robbery against another player.
- Protect your virtual balance with a protection feature.
- Report another player through the in-game police activity.
- Offer a virtual bribe to another player.
- Compete with other players for the highest balance.
- View the top players and top in-game thieves.
- Earn ranking medals based on leaderboard positions.

### Security & Cooldowns
- Apply cooldowns to selected activities.
- Check whether a player is eligible to perform an action.
- Protect accounts against in-game robbery for a limited period.
- Restrict sensitive bank-management commands to the configured owner.
- Validate account existence and balances before supported transactions.

### Owner Controls
- Add a predefined amount to the owner's game balance.
- Delete another player's virtual bank account.
- Reset the entire game bank database.
- Restrict owner-only operations using the configured Telegram user ID.

## Data Files

The module creates and uses local JSON files:

```text
bank_data.json   # Player accounts, balances, transfers, investments, and game state
codes_data.json  # Active and redeemed scratch-code records
```

Keep these files persistent between restarts. Back them up before making changes or resetting the game.

## Integration Requirements

This file is a bot plugin-module, not a complete standalone Telegram bot. It expects the host project to provide:

- A configured Pyrogram application named `app`.
- The imported `anony` module and its `app`, `db`, `lang`, and `config` objects.
- A Telegram bot already authenticated and running.
- Permission to handle messages and callback queries in the target chats.

The source imports `db`, `lang`, and `config`, although the banking logic primarily uses local JSON storage.

## Installation & Setup

1. Place `Bank_game.py` in the appropriate plugin directory of the host bot.
2. Confirm that the host project provides the required `anony` module.
3. Review the `BANK_OWNER` value and replace it with the intended administrator's Telegram user ID.
4. Review the game name, currency, bank names, starting balances, reward values, and cooldown settings.
5. Install the host project's dependencies, including a compatible Pyrogram version and `pytz`.
6. Start or restart the host bot and confirm that the plugin is loaded.

Example dependency installation:

```bash
pip install pyrogram pytz
```

The complete host bot may require additional dependencies beyond these.

## Important Notes

- This module uses local JSON files rather than a dedicated database for its main banking data.
- Keep the JSON files in a persistent and writable working directory.
- The owner ID is hard-coded in the supplied source and should be reviewed before deployment.
- Resetting the bank deletes the stored game accounts and related game records.
- The generated card-like numbers and security codes are fictional display values only. They must never be used or represented as real payment credentials.
- Some cooldown tracking uses in-memory variables, so those specific timers may reset when the bot process restarts.
- Review and test the module within the host bot before enabling it in public groups.
